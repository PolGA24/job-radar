# Perfil del candidato — Job Radar (EJEMPLO)

> Plantilla de ejemplo. Cópiala como `profile.md` y rellénala con tus datos:
>
> ```bash
> cp profile.example.md profile.md
> ```
>
> `profile.md` está en `.gitignore` y no se sube al repositorio.
> La IA lee este archivo para puntuar cada oferta, así que sé concreto sobre
> tu nivel real, lo que buscas y lo que te descarta.
> No pongas datos de contacto ni datos personales sensibles: este texto se
> envía a la API de IA en cada puntuación.

## Instrucciones para la IA que puntúa

Puntúa de 0 a 100 cuánto encaja la oferta con **este** candidato, no con un candidato ideal. Da más peso a lo que valoro y penaliza fuerte los requisitos duros que no cumplo. Si faltan datos en la oferta, no supongas lo peor: indícalo en "gaps".
